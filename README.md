# Booktionary

Look up words while you read and save them to the book you're reading.

- **Current Books / Past Books** on your profile
- **Look up a word** with a type-ahead dropdown, see its definition, and save it to that book's **New Vocab Words**
- Each word keeps the page number, the sentence from the book, and an everyday example
- **Review** a book's words as flashcards, and **quiz** yourself (words you miss come up more often)
- Works on a phone and can be added to the home screen
- Everything is stored on your device; use **Backup** (the ⋯ button) to download or restore a copy

Definitions come from the [Free Dictionary API](https://dictionaryapi.dev), word suggestions from [Datamuse](https://www.datamuse.com/api/), and book search from [Open Library](https://openlibrary.org/developers/api). None need an API key.

## Running it

```sh
npm install
npm run dev      # local development
npm run build    # production build in dist/
```
